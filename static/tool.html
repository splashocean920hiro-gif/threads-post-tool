投稿カレンダー

日付・時間はそれぞれ編集できます。本日以前の日付なら「投稿を実行」、未来の日付なら「投稿を予約」でそのまま操作できます。Threads APIが未設定の間は投稿実行がデモ動作（ランダムで成功/失敗）になります。

Threads API（Meta）

graph.threads.net ／ 未設定の間は投稿実行がデモ動作になります
→ Threads APIキーの取得ページ（Meta for Developers）を開く
① アプリを作成 → ②「Access the Threads API」を選択 → ③ 自分をThreadsテスターに追加してThreads側で承認 → ④「User Token Generator」で threads_basic / threads_content_publish 権限のトークンを生成 → ⑤ 表示されたUser IDとAccess Tokenを上の欄に入力。
短期トークンは graph.threads.net/access_token で60日の長期トークンに交換できます。
参照投稿を登録

Threadsで実際に伸びている投稿を、投稿者は問わず登録してください。必須は「本文」と反応数（いいね・リプライ・インプレッション）だけで、これが「どんな投稿が伸びるか」をAIに学ばせる主な材料です。リプライ（ツリー）は分かる場合のみ任意で追加してください。buzz-threads-collector拡張機能が収集した投稿は本文＋数値の形で自動反映されます。

投稿テンプレート（生成ルール）

投稿文を生成する際にGeminiへ渡すルール・汎用プロンプトです。文字数・口調・構成などの方針を自由に編集してください。生成ボタンを押すたびに、この内容がそのまま使われます。
